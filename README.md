# ID-PASS
KeyVault - 暗号化ID・パスワード統合管理マネージャー (v2.4)
KeyVault は、ブラウザ単体（単一のHTMLファイル）で完結する高セキュリティなID・パスワード・クレジットカード管理Webアプリケーションです。
外部サーバーへ一切データを送信せず、端末内（LocalStorage）において業界最高水準の暗号化方式（PBKDF2 60万回 ＋ AES-GCM-256）で安全にデータを保護します。
🌟 主な特長
1. 軍用レベルのローカル暗号化
￼ Web Crypto API を採用し、入力データは端末内でのみ暗号化・復号。
￼ クラウドや外部サーバーを介さないため、サービス終了や外部流出リスクがゼロ。
2. Face ID / Touch ID 生体認証連携（WebAuthn）
￼ 初回設定後は、マスターパスワードを入力することなく Face ID や Touch ID でワンタッチ解錠可能。
￼ 生体情報は端末内のセキュアエンクレーブで保護され、アプリ側には渡りません。
3. CSPRNG パスワード自動生成 ＆ 誤操作防止ロック（v2.4新機能）
￼ 暗号論的擬似乱数（12桁 / 16桁 / 20桁）で破られない強力なパスワードを生成。
￼ パスワード生成後や編集時は「🔒 保護ロック」が作動。誤タップによる意図しないパスワードの上書き・消失を100%防止し、変更時は Face ID またはマスターパスワードによる再認証を要求します。
4. クレジットカード専用管理
￼ カード番号の下4桁マスキング表示、ブランド自動判別（VISA / JCB / Mastercard / AMEX等）、Luhnアルゴリズム検証、有効期限切れ警告に対応。
5. 覗き見（ショルダーハッキング）対策
￼ 一覧画面にはサービス名とアイコンのみを表示。
￼ パスワードは標準で伏字（••••••••）、クリップボードへコピーした値は30秒後に自動クリア。
6. 安全なバックアップ ＆ 端末間同期
￼ 暗号化したままJSONファイルとしてエクスポート。
￼ 別の端末（PC ↔ iPhone等）に取り込む際も、最新の更新日時（⁠updatedAt⁠）を比較して安全に自動マージ。
🚀 使い方
1. セットアップ（初回起動時）
2. アカウントの登録と利用
￼ サービス追加: 右上の「サービスを追加」からサービス名、ID、パスワードを登録します。
￼ 詳細確認・コピー: 一覧からサービス名をタップすると詳細モーダルが開き、ワンタップでIDやパスワードをコピーできます。
￼ Face ID設定: ヘッダーの「Face ID」ボタンから生体認証を登録すると、次回から顔認証のみで解錠できます。
3. バックアップ（データの保管・移行）
￼ 書出（エクスポート）: 画面上部の「書出」から「暗号化バックアップ（推奨）」を選択し、ファイルを保存します。
￼ 読込（インポート）: 「読込」からバックアップファイルを選択すると、「既存データと統合（マージ）」または「すべて置き換え」を選択して復元できます。
📱 iPhone（iOS）でネイティブアプリ化する方法
本アプリは PWA（Progressive Web App）仕様に対応しています。
1. iPhone の Safari で本アプリのURLを開きます。
2. 画面下部の中央にある 「共有ボタン（四角から上矢印）」 をタップします。
3. メニューから 「ホーム画面に追加」 を選択します。
4. ホーム画面に専用アプリアイコンが作成され、タップするとSafariのURLバーがない全画面ネイティブアプリとして起動します。
🔒 セキュリティ仕様詳細
￼ 鍵導出関数: PBKDF2（HMAC-SHA256 / ストレッチング 600,000回 / 128bit Salt）
￼ 共通鍵暗号: AES-GCM 256bit（96bit IV / 毎回生成）
￼ 乱数生成: ⁠crypto.getRandomValues()⁠（棄却法による剰余バイアス完全排除）
￼ XSS防御: イベント委譲型アーキテクチャ、HTMLエスケープ、危険なURLスキーム（⁠javascript:⁠）遮断
￼ 自動ロック: アプリ切り替え・バックグラウンド移行時（60秒の離席猶予タイマー付き）
